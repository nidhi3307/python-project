# Password Generator (Letters & Numbers Only)

A simple Python CLI tool to generate secure random passwords containing **only letters and numbers**.  

---

## Features
- Generate passwords of any length  
- Use uppercase letters, lowercase letters, and numbers  
- No symbols included  
- Ensures at least one character from each selected type  

---

## Requirements
- Python 3.6 or higher  

No additional libraries required.  

---

## Usage

1. Clone or download the repository.
2. Run the script:

```bash
python password_generator_letters_numbers.py
